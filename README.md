## ◇ Careers & Internship Platform

DEVWAVE includes an integrated recruitment workflow designed for future engineering teams.

```text
Application
     ↓
Candidate Profile
     ↓
Application Review
     ↓
Shortlisting
     ↓
Internship Task
     ↓
Candidate Submission
     ↓
Evaluation
     ↓
Progress / Result
```

Internship programs support:

- 1-month duration
- 2-month duration
- 3-month duration
- Multiple technology domains
- CV submission
- Optional GitHub / LinkedIn / Portfolio
- Candidate workspace
- Practical tasks
- Submission tracking
- Evaluation workflow

**Internships are unpaid. Performance-based stipends may be provided according to program terms.**
